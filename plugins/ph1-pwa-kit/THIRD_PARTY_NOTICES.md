# Third-party skills

This plugin bundles three design skills published under the MIT License. Each skill folder contains its original LICENSE file.

| Skill | Source | Copyright | Changes in this plugin |
|---|---|---|---|
| `apple-design` | Emil Kowalski - `skills` repository (`skills/apple-design`) | (c) 2026 Emil Kowalski | None |
| `web-design-engineer` | ConardLi - `garden-skills` repository (`skills/web-design-engineer`), v1.3.0 | (c) 2026 garden-skills authors | Removed non-Claude files (`agents/openai.yaml`, `manifest.json`) and the README files. Skill content unchanged. |
| `landing-page-design` | Elaya - `ai-design-skills` repository (`skills/landing-page-design`) | (c) 2026 Elaya | Narrowed the `description` and the "Scope" paragraph to landing pages and marketing sites only, so its rules don't apply to app screens. All other content unchanged. |

To update a skill, replace its folder with the newer upstream version, keep its LICENSE file, re-apply the changes listed above, and bump the plugin version.

`app-ui-craft` is an original, condensed standard written for this plugin. It draws on ideas from `web-design-engineer` (anti-cliché rules, redesign modes, pre-delivery checklist) and `apple-design` (feedback, motion, typography), both MIT-licensed as above.
